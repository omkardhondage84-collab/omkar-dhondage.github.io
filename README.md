# Omkar Dhondage — Personal Portfolio

A futuristic purple, responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio structure/content
- `style.css` — futuristic purple theme + responsive layout
- `script.js` — mobile menu, reveal animations and back-to-top button

## How to run
1. Keep all three files in the same folder.
2. Open `index.html` in a browser.

## Before publishing
- Add your GitHub profile URL in the Contact section.
- Add your LinkedIn profile URL in the Contact section.
- Replace the upcoming project cards with real GitHub projects as you complete them.

## GitHub Pages
Create a GitHub repository (for example `portfolio`), upload these files to the repository root, then enable GitHub Pages from the repository settings. Your site can then be published through your GitHub Pages URL.
